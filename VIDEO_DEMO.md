## 5. Настоящие API и Angular

На компьютере переиспользовать туннель или запустить в отдельном терминале:

```sh
ssh -N -o ExitOnForwardFailure=yes -p 10015 -L 18881:127.0.0.1:43221 team15@85.143.113.230
```

Проверка без токена безопасно демонстрирует 401, не меняя БД:

```sh
curl -i http://127.0.0.1:18881/api/vehicles
```

Из `frontend/` в PowerShell (notes-прокси остаётся отдельным):

```powershell
$env:NOTES_API_URL='http://127.0.0.1:18880'
$env:PARKING_API_URL='http://127.0.0.1:18881'
npm start
```

Открыть `http://127.0.0.1:4200/admin/parking`. После приватного ввода DEMO_TOKEN_ADMIN показать автомобили, объекты и административные сессии, пагинацию, обновление, фильтр vehicleId. Токен в браузере только в памяти. Показать id/revision/endAt/status/paymentConfirmed=false. Водительский токен должен получить отказ на административном списке. Notes на 18880 требует отдельного туннеля к своему серверу; он не нужен для парковочной страницы.

Управление уже созданным API на ВМ без модели и smoke:

```sh
cd /home/team15/rwb-parking-api-20261031/runs/parking-sessions
./manage.sh status
# Только при необходимости поднять остановленный собственный профиль:
./manage.sh start
```

`stop` сохраняет том; `restart` перезапускает только API. Во время защиты без необходимости их не выполнять. Не использовать `--verify-existing` на демонстрационной БД: smoke создаёт данные. Старые сессии сохраняются; DEMO-CLIENT-A/B были подготовлены идемпотентно, актуальную занятость читать из API.

Фактический запуск показывать **только при наличии проверенного APK с этим хэшем и устройства**. Подготовленные команды, сейчас не подтверждающие сквозной запуск:

```sh

adb -s SERIAL reverse tcp:18881 tcp:18881
adb -s SERIAL install -r app-debug.apk
```

В приложении явно выбрать сетевой режим и адрес `http://127.0.0.1:18881`, приватно ввести водительский токен. Для эмулятора допустим `http://10.0.2.2:18881`. Пока устройство недоступно, сказать **«Android → API → Angular не проверен»**, показать только APK-отчёт/тесты. Автономное демо обозначать отдельно, оно не работает с серверной БД.
