# Содержание project-handoff.zip

Рабочий снимок для планирования. Начните с [CURRENT_STATE.md](CURRENT_STATE.md). Код и исходные результаты при сборке не изменялись.

| Группа | Что включено | Файлов без манифеста и отчёта упаковки |
|---|---|---:|
| [root files] | Скрипты, README, зависимости, Docker/Compose, безопасные примеры конфигурации, CURRENT_STATE | 17 |
| app | Актуальные Python-модули | 10 |
| docs | Текущая адаптация stage2, машинные файлы без изменения | 24 |
| examples | Небольшие требования/спецификации/параметры, без больших геоданных | 6 |
| resources | Текст регламентов, извлечённые таблицы, четыре шаблона, mapping/backlog | 22 |
| runs | Результаты stage2, происхождение/метрики/ошибки, отчёты адаптации и диагностики | 58 |
| schemas | JSON Schema v2 | 1 |
| static | HTML/CSS/JS интерфейс пайплайна | 3 |
| tests | Существующие тесты | 4 |

## Основные материалы

- Актуальные исходники взяты из рабочего дерева, включая незакоммиченные изменения; base Git-коммит/ветка указаны в CURRENT_STATE.
- `docs/stage2/` - актуальное Markdown-оформление; `runs/stage2/reviewed-specification/` - исходная инженерная ревизия. Их машинные контракты идентичны; происхождение не подменено генерацией Qwen.
- `runs/stage2/original-run/`, `qwen-attempt-1/2/` и `stage2-report.json` сохраняют реальные ошибки/usage и отделяют модель от инженерной работы.
- `runs/documentation-standards/preparation-report.json` и протоколы - основание последних 50 успешных локальных тестов и проверок; повторных прогонов при сборке нет.
- `HANDOFF_MANIFEST.json` содержит полный относительный перечень/размеры/SHA-256; `HANDOFF_CHECK.json` описывает проверку безопасности и состава. Это метаданные упаковки, не новые результаты испытания программы.

## Что исключено

`.env` и секретная конфигурация, ключи/пароли, `.git`, кэши/IDE, `.venv`/node_modules/колёса и установленные зависимости, все PDF, исходные `spb.json`/`response.json`, изображения PDF-страниц, резервные копии, другие ZIP/TAR/GZ. CI/CD-конфигурации не найдены и не создавались.

Оригинальные PDF и большие геоданные не удалены из рабочего проекта, только исключены из архива. Отдельные ссылки на оригиналы/источники и команды полной проверки документации потребуют вернуть исключённые файлы. Текст/таблицы, хэши и отчёты включены. Исторические манифесты этапов не определяют состав этого пакета.
