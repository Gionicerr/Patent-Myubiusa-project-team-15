Основание: [контракт](design.json), [шаблон сервиса](../../resources/standards/russtech/templates/service.md). Ответственные и согласования не предоставлены.

## Описание

ApplicationApi проектируется для прав доступа, координат, matching, сессий, событий, Clock и демонстрационного платёжного адаптера. Технология из контракта: ASP.NET Core / .NET 10 / C# 14. Публикация HTTP API описана в [OpenAPI](openapi.json); [пример метода](api-method-example.md). Архитектура и данные: [системный анализ](system-analysis.md).
