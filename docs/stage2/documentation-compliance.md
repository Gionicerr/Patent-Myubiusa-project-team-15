# Соответствие stage2 регламентам

Итог: **частичное соответствие, подготовительная адаптация**. Наличие заголовков не является полным заполнением шаблона или согласованием. Исходные JSON, FR-ID, схемы и OpenAPI сохранены.

## Поддерживается

- Структурированный анализ с FR-ID, цитатами и критериями; связи с TC и API.
- Типизированная модель с required/PK/FK/индексами; API с параметрами, телами, ответами и правами; состояния экранов и события с дедупликацией.
- Отделение допущений, ограничений и открытых вопросов; статусы/usage реальных запусков отделены от инженерной ревизии.
- Совместимость v1/v2; существующие проверки типов/ссылок/OpenAPI остаются действующими.

## Добавлено в этой адаптации

- Общие положения: TO BE, история, незаполненные ответственные/согласования, термины и ссылки на фактические артефакты.
- Оглавление с существующими якорями и ссылки между документами.
- Четыре переносимых [шаблона](../../resources/standards/russtech/README.md) и редактируемая заготовка PlantUML.
- Один [неполный метод](api-method-example.md) по существующему контракту и [паспорт целевого сервиса](service-example.md); это демонстрация, не полная документация всех сервисов/методов.

## Не хватает данных

Нет реальной истории/авторов/согласований/Jira, корпоративного глоссария, UC-ID и полного UC, спецификации каждого UI-контрола/маппинга, Figma, исходников проектных sequence/ERD, per-method алгоритма/обращений к БД/примеров/кэша, описания интеграций с частотами/триггерами, паспорта эксплуатации/измерений и ADR со значимыми альтернативами. Наличие role/steps или компонентов не выдаётся за эти данные.

Подробности: [таблица соответствия](../../resources/standards/russtech/mapping.md), [неоднозначности и план](../../resources/standards/russtech/backlog.md). Недостающие поля помечены как будущие, действующая JSON Schema v2 не расширяется.

## Конкретное расхождение именования API

RULES с.15 указывает избегать глаголов в путях; существующие `/api/sessions/{sessionId}/confirm` и `/api/admin/clock/advance` этому указанию не следуют. По границам задания маршруты не переименованы. Требуется отдельно согласовать исключение либо совместимое версионирование (U-12). Это не ошибка структуры OpenAPI, а вопрос корпоративного стиля.

## Не выполнялось

Запросы Qwen, настройка доступа, подключение/перезапуск ВМ, генерация/запуск целевого приложения, БД/миграции, CI/CD, `/health`, `/metrics`, мониторинг, endpoint перезапуска и эксплуатационные измерения. Предыдущие запуски и ошибки сохранены, действующий сервер не затрагивался.
