# Проверки подготовительной адаптации

## Выполнено

- Сохранены и визуально сверены 5 PDF, 38 страниц; хэши исходников совпадают с реестром.
- Регрессионные тесты Python-пайплайна: **50 тестов прошли**. Это тесты пайплайна и документов, не целевого приложения.
- Проверены относительные ссылки/якоря, маркировка пустых шаблонов, наличие редактируемой заготовки PlantUML.
- Девять машинных файлов сохранены побайтно, FR-ID сохранены. Прежние JSON Schema и `app/contracts.py` не изменены.
- Сохранённый OpenAPI валиден и совпадает с проектом v2; пример getSession не добавляет коды и схемы ответа.
- Исходные результаты stage2 сохранены отдельно; общий статус соответствия корпоративным шаблонам остаётся **частичным**.

## Что не проверялось и не выполнялось

Нет новых вызовов Qwen, доступа/перезапуска ВМ, разработки приложения, БД, CI/CD, мониторинга или испытаний эксплуатационных пределов. Работающий сервер не затрагивался. Состояние его живой памяти не запрашивалось; сохранены ранее выгруженные результаты и их хэши.

Заготовка PlantUML не является согласованной/отрендеренной диаграммой системы. Макеты, авторы, согласования и измерения не выдумывались.

## Проверка воспроизводимости

```text
python -m unittest discover -s tests -v
python check_documentation.py --output runs/documentation-standards/documentation-checks.json
python check_specification.py docs/stage2 --output runs/documentation-standards/contract-validation.json
```

Полные локальные протоколы: `runs/documentation-standards/unit-tests.txt`, `documentation-checks.json`, `contract-validation.json`, `before-hashes.json`. Резервные копии источников находятся в `runs/documentation-standards/backup/`, без конфигурации секретов.

Применимость и незаполненные требования: [анализ соответствия](documentation-compliance.md), [будущие задачи](../../resources/standards/russtech/backlog.md).
