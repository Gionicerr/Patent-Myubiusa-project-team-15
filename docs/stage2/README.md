## Повторное локальное оформление

```text
python adapt_documentation.py --source runs/stage2/reviewed-specification --output docs/stage2
```

Команда не вызывает Qwen, не меняет исходный запуск и сохраняет JSON-контракты побайтно. Она обновляет базовые Markdown/CSV и профиль; демонстрационные страницы и анализ пробелов поддерживаются отдельно. Исходный каталог нельзя использовать одновременно как выходной. Для проверки контрактов:

```text
python check_specification.py docs/stage2 --output runs/documentation-standards/contract-validation.json
```

Эта проверка подтверждает структуру/согласованность контракта, не полное заполнение корпоративных шаблонов и не испытание приложения.
